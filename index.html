sophii.co test harness

Visual demos for the packages in this monorepo. Each demo is a static HTML page that loads its package's compiled build and exercises the API.

Serving: run npm run serve from the repo root, then open http://localhost:8080/.
Tag legend: local loads the built dist/ from this checkout - cdn loads the published version from jsDelivr.

avoidance.js - particle avoidance effect

  • avoidance-test.html local Four 500x500 particle containers, each with different physics parameters. Move your mouse to scatter the particles. Add/remove/stop-start buttons per container.
  • responsive-test.html local Responsive-layout variant.
  • production-test.html cdn Same demo, but loads avoidance.min.js from the published npm package via jsDelivr. Smoke-test that the production CDN copy still works.

draggamil.js - touch-friendly draggable elements

  • draggamil-test.html local Four red boxes in a goldenrod-bordered container. Click and drag (mouse or touch).
  • production-test.html cdn Same demo, but loads draggamil.min.js from jsDelivr. Smoke-test that the production CDN copy still works.

avoidance-test - import-flavor smoke tests

  • esmodule-import-test.html local 14 aquamarine circles in a full-viewport container, rendered via an ESM-bundled build of avoidance.
  • commonjs-import-test.html local Same as above, via the CommonJS bundle.

Note: helpers/avoidance-cloud.html and helpers/draggamil-docready.html in this repo are 1-line embed snippets for CDN use, not standalone demos - they won't render anything visually on their own.
